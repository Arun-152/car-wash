# 🚗 Car Wash Booking System

A production-level **MERN Stack Car Wash Booking System** that enables customers to book car wash services online while providing an Admin Panel to manage services, bookings, shop availability, reports, and customers.

## 🌐 Live Demo

**Website:**  https://car-wash-virid.vercel.app/

---

# 📅 Booking Workflow

```
Register
    ↓
Login
    ↓
Browse Services
    ↓
Select Vehicle
    ↓
Choose Date & Time
    ↓
Select Available Slot
    ↓
Online Payment
    ↓
Booking Confirmed
    ↓
Service Completed
```

---

# 🔄 Cancellation Workflow

```
Booking Confirmed
        ↓
User Requests Cancellation
        ↓
Admin Reviews Request
        ↓
Approved
        ↓
Refund Added to Wallet
        ↓
Booking Cancelled
```

# 🚀 Installation

### Clone the Repository

```bash
git clone https://github.com/your-username/car-wash-booking.git
```

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
